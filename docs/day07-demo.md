```text

Режим: semantic, top-k: 5

Ответ с retrieval:
При замене embedding-модели обычно требуется пересоздать все векторы в индексе: документы и вопрос должны кодироваться совместимой моделью [1].

Источники:

Векторные представления текста
Embedding — это числовой вектор, который описывает смысл текста. Похожие по смыслу вопросы и фрагменты обычно получают близкие векторы, даже если используют разные слова. Благодаря этому semantic search способен находить контекст не только по точному совпадению терминов.
Документы и пользовательский вопрос должны кодироваться совместимой embedding-моделью. Замена модели обычно требует пересоздания всех векторов в индексе. Размерность вектора также должна совпадать с настройками хранилища.
Секреты доступа к embedding API не сохраняют в коде или репозитории. Их передают через переменные окружения, а ошибки сети и ограничения API обрабатывают явно.

Weaviate как векторное хранилище
Weaviate хранит объекты, их свойства и векторные представления. Для учебного RAG-сервиса один объект обычно соответствует одному чанку. Вместе с текстом сохраняются имя исходного файла, номер чанка и другие метаданные для цитирования.
Схема коллекции определяет названия и типы свойств, а также способ векторизации. Если embeddings вычисляет приложение, в Weaviate передают готовый вектор. Такой режим позволяет контролировать модель и повторно использовать один и тот же embedding-клиент.
Перед массовой загрузкой полезно создать коллекцию и проверить соединение. Повторная индексация должна учитывать дубликаты, иначе одинаковые чанки ухудшат результаты поиска.

Перед массовой загрузкой полезно создать коллекцию и проверить соединение. Повторная индексация должна учитывать дубликаты, иначе одинаковые чанки ухудшат результаты поиска.
```
