Векторные представления текста

Embedding — это числовой вектор, который описывает смысл текста. Похожие по смыслу вопросы и фрагменты обычно получают близкие векторы, даже если используют разные слова. Благодаря этому semantic search способен находить контекст не только по точному совпадению терминов.

Документы и пользовательский вопрос должны кодироваться совместимой embedding-моделью. Замена модели обычно требует пересоздания всех векторов в индексе. Размерность вектора также должна совпадать с настройками хранилища.

Секреты доступа к embedding API не сохраняют в коде или репозитории. Их передают через переменные окружения, а ошибки сети и ограничения API обрабатывают явно.
